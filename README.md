# 📊 Controle e Gestão de Treinamentos — Excel

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma solução em Microsoft Excel para gerenciamento e acompanhamento de treinamentos corporativos.

A proposta é organizar informações de funcionários, instrutores e treinamentos em uma estrutura centralizada, facilitando o controle dos registros, a consulta de informações e o acompanhamento de prazos.

O desenvolvimento utiliza recursos avançados do Excel, fórmulas dinâmicas, tabelas estruturadas, validação de dados e mecanismos de pesquisa para tornar o processo mais organizado e eficiente.

## 🎯 Objetivo

Desenvolver uma ferramenta prática para auxiliar empresas no gerenciamento de treinamentos, permitindo acompanhar informações importantes, identificar pendências e melhorar a organização dos processos internos.

## ⚙️ Funcionalidades

- **Painel inicial:** centralização da navegação e acesso às principais funcionalidades.
- **Cadastro de instrutores:** organização dos responsáveis pelos treinamentos.
- **Cadastro de treinamentos:** registro de nome, categoria, objetivo, carga horária, modalidade, instrutor e validade.
- **Pesquisa de treinamentos:** localização de registros por nome, categoria ou instrutor.
- **Busca por identificação:** consulta de informações utilizando códigos de identificação.
- **Controle de funcionários:** organização da base de colaboradores.
- **Controle de pendências:** acompanhamento dos treinamentos que precisam de atenção.
- **Controle de vencimentos:** identificação de treinamentos conforme suas datas de validade.

## 🔎 Lógica de funcionamento

O projeto utiliza bases estruturadas para organizar os dados e fórmulas para realizar pesquisas e apresentar informações automaticamente.

Na tela de pendências, por exemplo, a função FILTRO permite consultar os registros da base principal de acordo com critérios definidos, como situação do treinamento e data de vencimento.

A utilização de referências estruturadas facilita a manutenção das fórmulas e a expansão das bases de dados.
